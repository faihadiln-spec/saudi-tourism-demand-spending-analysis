# GitHub Upload Steps

Use these commands after creating an empty GitHub repository named:

`saudi-tourism-demand-spending-analysis`

```bash
cd saudi-tourism-demand-spending-analysis
git init
git add .
git commit -m "Initial commit: Saudi tourism demand and spending analysis"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/saudi-tourism-demand-spending-analysis.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
